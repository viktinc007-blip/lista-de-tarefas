# 📋 Minha Lista de Tarefas

Esse é um projetinho que eu fiz pra treinar JavaScript e mexer com o DOM.  

## Funciona assim

- Dá pra **adicionar tarefas** digitando no campo e clicando em "Adicionar".  
- Cada tarefa vem com um **botão de excluir**, pra remover se quiser.  
- Tudo acontece na hora, sem precisar atualizar a página.

## Tecnologias

- HTML  
- CSS  
- JavaScript

## Observações

- Fiz esse projeto sozinho, só pra praticar e aprender a mexer com listas e eventos.  
- O visual é simples, mas cumpre a função 😄
